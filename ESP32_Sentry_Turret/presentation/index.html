THE SCIENCE

Ultrasonic Distance

Distance = (Time x 340) / 2

Sound travels at 340 m/s. We send a pulse, time the echo, and calculate distance. Dividing by 2 because sound travels there AND back.

Infrared Detection

All warm bodies emit IR

The PIR sensor detects changes in infrared radiation. When a person walks by, the sensor registers the heat difference against the background.

PWM Servo Control

1ms = 0°   |   1.5ms = 90°   |   2ms = 180°

Servo motors are controlled by pulse width. A 50Hz signal (20ms period) with varying pulse width sets the angle precisely.

State Machine Logic

IF condition THEN next_state

The software uses a state machine — a computer science concept where the system is always in one defined state and transitions based on rules.

CHALLENGES & SOLUTIONS

Flash Write Protection

Boya flash chip re-enabled write protection after every power cycle — uploads failed with MD5 errors. Fix: Custom script clears the protection bit before every upload.

GPIO 12 Boot Crash

GPIO 12 is a strapping pin that sets flash voltage. Attaching a servo here corrupted the flash on every boot. Fix: Moved tilt servo to GPIO 32.

Servo Power Issues

MG996R servos drew too much current from the ESP32, causing random resets. Fix: External 6V battery pack with common ground.

Trigger Mechanism

Hot glue failed under servo torque, detaching the mount mid-test. Servo arm too short to pull the trigger. Fix: Re-glued with longer arm for more mechanical leverage.

Serial Port Conflicts

Arduino IDE held COM4 open, blocking command-line tools from accessing the board. Fix: Close IDE before running esptool commands.

Download Mode Required

ESP32 sometimes refused to connect during upload. Fix: Manual boot mode — hold BOOT, plug USB, release after 2 seconds.
